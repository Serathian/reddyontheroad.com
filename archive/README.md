# Archive

This folder contains **outdated design iterations** from the project's development process. These files are preserved for reference but should **NOT** be used for future development.

## Why These Files Are Archived

During the design process, we explored multiple aesthetic directions:
1. **Coffee Palette** (Warm browns + yellowish cream) - Rejected as too bright/warm
2. **Formal Typography** (Abril Fatface + Merriweather) - Rejected as too rigid
3. **Early Prototypes** - Superseded by journal aesthetic

**Current Design**: Leather journal aesthetic with aged paper, handwritten fonts, and vintage textures.
