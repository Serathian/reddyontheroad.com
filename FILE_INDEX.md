## 🎯 Common Tasks

### "I want to see the current design"
→ Open `journal-prototype.html` in browser

### "I want to understand the color palette"
→ Open `journal-palette-preview.html` in browser  
→ Read `JOURNAL_DESIGN_SYSTEM.md` → Color Palette section

### "I want to implement the map animation"
→ Read `MAP_ANIMATION_IMPLEMENTATION.md`  
→ Reference code examples in that document

### "I want to understand the project scope"
→ Read `PROJECT_README.md` → Project Overview section

### "I want to know what to build next"
→ Read `PROJECT_README.md` → Next Steps for Development section

### "I want to use the CSS variables"
→ Copy `design-system-styles.css` into your project  
→ Or reference variable names from `JOURNAL_DESIGN_SYSTEM.md`

### "Why were certain design decisions made?"
→ Read `PROJECT_README.md` → Design Decisions Log section  
→ Or check `archive/README.md` for historical context

## ⚠️ What NOT to Use

- ❌ Files in `archive/` folder (outdated designs)
- ❌ Old color palette (#FEF3C7 yellowish tones)
- ❌ Old fonts (Abril Fatface, Merriweather)
- ❌ `README.md` in archive (replaced by PROJECT_README.md)
