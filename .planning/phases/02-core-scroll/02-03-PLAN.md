**New implementation:**

1. Update imports in app/page.tsx:
   - Add: `import { Carousel } from '@/app/components/Carousel/Carousel'`
   - Keep: `import { SplitLayout } from '@/app/components/SplitLayout/SplitLayout'`
   - Keep: `import { mockDailyEntries } from '@/lib/mockData'`

2. Replace content prop with Carousel:
```tsx
export default function Home() {
  return (
    <SplitLayout
      mapPlaceholder={
        <div className={styles.mapPlaceholder}>
          <p>Map integration coming in Phase 3</p>
        </div>
      }
      content={
        <div className={styles.carouselWrapper}>
          <Carousel entries={mockDailyEntries} />
        </div>
      }
    />
  )
}
```

3. Update app/page.module.css:
   - Remove old entry list styles (if any)
   - Add `.carouselWrapper` for vertical centering:
     ```css
     .carouselWrapper {
       display: flex;
       align-items: center;
       height: 100%;
       overflow: hidden; /* Prevent double scrollbars */
     }
     ```
   - Add `.mapPlaceholder` for consistent placeholder styling:
     ```css
     .mapPlaceholder {
       display: flex;
       align-items: center;
       justify-content: center;
       height: 100%;
       background: var(--journal-paper);
       color: var(--ink-faded);
       font-family: var(--font-mono);
       font-size: 0.875rem;
     }
     ```

**Why wrapper div:** Carousel needs to be vertically centered in content pane. Flexbox wrapper with `align-items: center` centers carousel vertically without affecting horizontal scroll behavior.

**Why overflow: hidden on wrapper:** Prevents potential double scrollbar if both wrapper and carousel have scrollable overflow. Carousel handles all scrolling.

**Note:** This is NOT a Server Component data fetch (that comes later with real CMS). Currently using static mockDailyEntries import - page remains a Server Component, Carousel is Client Component for IntersectionObserver.
