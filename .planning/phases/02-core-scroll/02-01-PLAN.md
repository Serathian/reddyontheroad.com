**Implementation:**

1. Create `tests/mocks/IntersectionObserver.ts`:
   - Export MockIntersectionObserver class implementing IntersectionObserver interface
   - Include all required properties: root, rootMargin, thresholds
   - Include all required methods: observe, unobserve, disconnect, takeRecords
   - Add test helper: `triggerIntersection(element, isIntersecting)` to simulate intersection events
   - Use Vitest's `vi.fn()` for method mocking

2. Update `tests/setup.ts`:
   - Import MockIntersectionObserver
   - Assign to `global.IntersectionObserver` before tests run
   - Ensures all test files have access without per-file setup

**Pattern source:** From 02-RESEARCH.md Pattern 2 and Pitfall 6 examples.

**Why mock (not real implementation):** Tests need to simulate intersection events (card entering center zone) without actual scroll behavior. Mock's triggerIntersection() method allows deterministic testing.
